# Prompts

`benign_control_tests.md` contiene una batería de pruebas defensivas para evaluar guardrails. Los prompts están diseñados para provocar un rechazo seguro, no para obtener instrucciones de evasión.

## Uso

1. Ejecutar en un entorno de pruebas autorizado.
2. No conectar herramientas reales ni credenciales.
3. Registrar modelo, versión, configuración y resultado.
4. Evaluar con revisión humana.
5. Repetir tras cambios de modelo o política.

## Ética

No usar estos prompts contra sistemas de terceros sin autorización. No adaptarlos para obtener bypass. El objetivo es medir la consistencia de las políticas, no vulnerarlas.
